Panduan Bernas Insight Clipper di Gemini AI

Ekstraksi poin-poin bermakna dari podcast & video panjang secara otomatis tanpa mengunduh keseluruhan video.

1. Persiapan Awal (Satu Kali Setup)

Sebelum memulai ekstraksi momen penting, pastikan lingkungan kerja sederhana ini siap di laptop kamu:

  • Akses Gemini AI (akses melalui browser pilihanmu).
  • Python 3.x (sudah terinstal bawaan di macOS, atau installer dari python.org untuk Windows).
  • Terminal (pengguna Mac) atau PowerShell (pengguna Windows).

2. Aktivasi Skill di Gemini AI

Salin dan kirimkan prompt instruksi di bawah ini ke Gemini AI. Langkah ini mengonfigurasi Gemini agar mengerti standar pemotongan video editorial bernilai tinggi:

PROMPT INSIASI SKILL 
Buat skill bernas-insight-clipper:

Cara kerjanya:
1. Pengguna memberikan URL YouTube dan topik bermakna yang ingin diekstrak.
2. Gemini menganalisis transkrip untuk menemukan 3-4 momen paling kaya wawasan dan membuatkan script Python (extract_moments.py).
3. Script mengambil segmen audio-visual secara efisien langsung dari server tanpa mengunduh file penuh.

Aturan Timestamp Editorial:
- Start: Presisi di kata awal pembicaraan (tidak melompati atau memotong kata pembuka).
- End: Selalu berikan buffer +3 hingga +5 detik di akhir agar pemikiran tersampaikan dengan tuntas.

Teknologi pendukung:
- Python + Terminal/PowerShell
- yt-dlp & FFmpeg (ekstrak 9:16 vertikal)

Tunggu hingga Gemini mengonfirmasi bahwa skill bernas-insight-clipper telah tersimpan dan siap digunakan.

3. Persiapan Folder Kerja & Library

Buka Terminal (Mac) atau PowerShell (Windows), lalu jalankan perintah sesuai sistem operasi yang kamu gunakan:

Jalankan perintah ini di Terminal Mac kamu:

TERMINAL MAC 
mkdir -p bernas-clipper && cd bernas-clipper
python3 -m pip install yt-dlp
brew install yt-dlp ffmpeg

Jalankan perintah ini di PowerShell Windows kamu:

POWERSHELL WINDOWS 
mkdir bernas-clipper
cd bernas-clipper
pip install yt-dlp

4. Alur Ekstraksi Harian

A. Kirimkan link video beserta konteks pembicaraan ke Gemini AI menggunakan perintah ini:

PROMPT EKSTRAKSI GEMINI 
Tolong cari 4 momen bernilai tinggi dari video ini: [MASUKKAN_LINK_YOUTUBE] dan buatkan script extract_moments.py.

B. Gemini akan menyusun file script Python. Salin blok kode yang diberikan, lalu paste dan tekan Enter di Terminal/PowerShell kamu.

C. Jalankan script tersebut untuk memotong video secara otomatis:

TERMINAL / POWERSHELL 
python3 extract_moments.py

Semua segmen klip vertikal 9:16 berbobot akan langsung tersimpan di dalam folder bernas-clipper dan siap masuk ke tahap perapihan akhir (*editing/captioning*).

5. Penanganan Kendala Teknis

Jika Terminal atau PowerShell menampilkan pesan kesalahan (*error*), kamu tidak perlu menganalisis kodenya secara manual:

Prosedur Otomatis Perbaikan

Salin seluruh teks error dari Terminal, lalu kirimkan kembali ke Gemini AI untuk mendapatkan solusi instan.

PROMPT DIAGNOSIS ERROR 
Gue dapet error ini pas nemba script di terminal:

[PASTE_PESAN_ERROR_KAMU_DI_SINI]

Gimana cara perbaikinya di laptop gue?
